Returns the index id of parameter name

Returns the number of parameters

 

.FAST.GetLen()

Returns the number of registers per parameter

 

.FAST.GetTimeStart()

Returns the initial time in seconds

 

.FAST.GetTimeEnd()

Returns the end time in seconds

 

.FAST.GetTime(int idtime)

Returns the idtime th time (idtime goes from 0 to  BMR FAST GetLen())

 

.FAST.GetData(int idtime, int idparam)

Returns the idtime th value of parameter idparam (idtime goes from 0 to  BMR FAST GetLen())

 

.FAST.GetAvg(int idparam, int idbegin, int idend)

Returns the average value for parameter idparam

 

.FAST.GetMax(int idparam, int idbegin, int idend)

.FAST.GetMin(int idparam, int idbegin, int idend)

.FAST.GetArray(int idparam, int idbegin, int idend, double **data, int *dim)

.FAST.LoadFile(const char *file)

Open a .dat or .fst FAST file to read or save parameters

 

.FAST.SaveFile(const char *file)

Saves the .dat or .fst FAST file opened with FAST LoadFile() (if file is ""), or to the file indicated in file

 

.FAST.SetVar(const char *name, const char *paragraph, const char *value)

Sets the value of a var after paragraph. If paragraph is "", the value is set every time var appears in the file

 

.FAST.GetVar(const char *name, const char *paragraph)

Reads the value of a var after paragraph. If paragraph is "", it is read the first time var appears in the file
